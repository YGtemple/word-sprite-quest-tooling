### 1. 快手可灵 KLING（可灵 AI 3.0 / 3.0 Omni / O3 / 2.6 / 2.5 Turbo / Kling-Avatar 数字人）

**来源链接**：
- https://ir.kuaishou.com/zh-hans/news-releases/ （2.6 音画同出，2025-12-05）
- http://caijing.chinadaily.com.cn/a/202602/05/WS69844192a310942cc499e677.html （3.0 系列发布，2026-02-05）
- http://finance.people.com.cn/n1/2025/0919/c1004-40567753.html （Kling-Avatar 数字人，2025-09-19）
- https://www.ifanr.com/1661163 （《纸手机》主创对话，2026-05-09）
- https://kling.ai/blog/kling-3-subject-binding-character-consistency （Subject Binding，2026-06-26）
- https://www.tmtpost.com/8018550.html （钛媒体三模型测评，2026-06-08）

**类别**：闭源商业产品（网页版 + APP + API），快手科技。

**核心能力**：
- 视频 3.0 / 3.0 Omni：All-in-One 多模态输入输出，最长 15 秒连续生成（续写可达 2-3 分钟，博主称支持 5 分钟长视频），智能分镜（正反打对话、跨分镜转场），图生视频 + 主体参考二次锚定。
- Kling O3：皮肤肌理更自然、编辑感更强（比 3.0 少一点"时尚杂志理想化脸"）。
- **"全能参考"**：上传 3-8s 角色视频或多图素材锁定主体；可在图生视频基础上再加多图 / 视频主体做二次锚定。
- 音画同出（2.6 起）：文本 / 图直接生成带人声、音效、环境音的视频，支持中英双语及粤语、四川话、东北口音、北京口音等方言。
- Kling-Avatar 数字人：上传人像 + 音频驱动口型，唇形与时序高度一致，复杂音节（如 [truːθ]）也能还原；可由提示词驱动"眼神专注自信地唱歌""微笑与观众互动"等表演状态。
- 音色绑定：主体资产中提取并锁定音色，跨镜头保持同一角色声音。

**在真人写实短剧场景的优秀点**：
1. **情感短片爆款验证最充分**：潮汕两人团队用可灵 3.0 Omni 三天做出《纸手机》（清明给去世奶奶烧手机的亲情短片），全网播放超 4000 万、央视 / 人民日报转发；车内 1 分多钟无台词长镜头靠"窗外景色 + 小男孩情绪递进 + 车内颠簸感"提示词完成。
2. **皮肤 / 光影质感第一梯队**：钛媒体实测"同样是 1080P，可灵生成的角色皮肤细节、光影效果都强出一截"；爱范儿 / Pexo 评价"可灵 3.0 在写实人脸对比中领先，毛孔、发丝、皮肤纹理达摄影级"。
3. **方言 / 口音表演**：粤语、四川话、东北口音原生生成，适配家庭 / 怀旧 / 乡土题材。
4. **职场 / 悬疑题材实测**：钛媒体圆桌戏《最后的证词》中，可灵"敢于用近景，角色从抬眼、质问，面部表情随说话顿挫，到最后情绪爆发、面部纹路走向都很到位"；擦泪镜头"用手背揉鼻子顺势抹泪比手指直接擦泪更自然"。
5. **成本优势**：钛媒体测 15 秒 1080P 视频，可灵积分消耗约为 Seedance 2.0 的 **58%**。

**局限或门槛**：
- **口型是最大短板**：钛媒体实测"声画直出视频大部分做不到口型一致，角色一长时间说话就容易露馅，最好后期配音"；偶发"男人的台词声音从女性角色嘴里说出来"。
- 多人会议场景容易"角色识别错误、分裂成两个人"；偶发眼神看错位。
- 3.0 Omni 初期仅面向黑金会员；免费用户每天约 66 积分 ≈ 6 条视频，付费 58 元 / 月起，大杯 234 元 / 月、超大杯 586 元 / 月。

**适合题材标签**：情感亲情 / 年代怀旧 / 家庭 / 职场悬疑 / 乡土

### 2. 字节即梦 Dreamina / Seedance（Seedance 1.0 / 1.5 Pro / 2.0 / 2.5）

**来源链接**：
- https://seed.bytedance.com/zh/seedance （官方）
- https://jimeng.jianying.com/ （即梦网页版）
- 量子位 Vidu Q2 参考生实测（含 Seedance 对比，2026-06）
- 钛媒体三模型测评（2026-06-08）

**类别**：闭源商业产品，字节跳动豆包 / 即梦团队自研。

**核心能力**：
- Seedance 2.5：独立适配器，可按确认的镜头方案使用**多参考**与最长 **30 秒**生成单元。
- Seedance 2.0：保留原版提示词结构，最长 15 秒；本仓库 `doubao-free` 插件解锁的正是这一档。
- 1.5 Pro / 2.0：支持图生视频 + 首尾帧控制，运镜指令遵循度高。
- 与豆包客户端深度整合，提示词可用自然语言描述镜头与情绪。

**优秀点**：
1. **运镜与镜头语言最听话**："推镜至眼部特写，随后拉远至中景"这类复合运镜能一次生成，分镜衔接比多数国产模型稳。
2. **多参考一致性**：2.5 支持多图参考锁定多个主体，多人对手戏（正反打）崩坏率低于同期国产模型。
3. **豆包生态联动**：`doubao-free` 插件解锁 15 秒后，配合无水印下载，成片链路最短。

**局限**：
- 情感细腻度（微表情、眼眶泛红）弱于可灵，"哭戏"常显僵硬。
- 音画同出的方言支持不如可灵。
- 时长 2.5 才有 30 秒，2.0 及以下最长 15 秒（需续写拼接近 2-3 分钟）。

**适合题材标签**：都市 / 职场 / 悬疑 / 反转 / 广告带货（运镜要求高的）

### 3. 生数科技 Vidu（Vidu Q1 / Q2 参考生 / 多主体）

**来源链接**：
- https://www.vidu.cn/ 、https://www.vidu.com/
- 量子位 Vidu Q2 参考生实测（2026-06）
- 光明网 Vidu Q2 微表情报道（2026-06）

**类别**：闭源商业产品，生数科技 + 清华系。

**核心能力**：
- **参考生（Reference-to-Video）**：上传 1-4 张角色图，锁定同一人物跨镜头一致，业界最早做这个方向的产品之一。
- 多主体参考：Q2 支持同时锁定多个人物 + 场景。
- 微表情专项优化：光明网报道 Q2 在"眼眶泛红、嘴角颤动"等微表情上明显优于前代。

**优秀点**：
1. **角色一致性第一梯队**：多集连载短剧的"主角换集不变脸"主要靠它。
2. **动漫转真人**：参考生可把动漫设定图转成真人风格，适合 IP 改编。
3. 生成速度快，4 秒级出片，适合大量试错。

**局限**：
- 真人皮肤质感弱于可灵（毛孔 / 发丝细节不足）。
- 口型同步一般，长对白建议后期配音。
- 免费额度少，重度使用需订阅。

**适合题材标签**：情感 / 都市 / 治愈（需要主角跨镜头一致的）

### 4. 爱诗科技 PixVerse（V4 / V5.6 / V6）

**来源链接**：

- 中国日报网 PixVerse V6 发布

**核心能力**：

**局限**：
- 角色一致性弱于 Vidu / 可灵。

## 四、存疑与未覆盖项

- 部分模型版本号（如 Wan 3.0、SkyReels V4）未找到 2026-10 前的官方确认，时效存疑。
- 成本对比（可灵 58% vs Seedance）来自单一来源（钛媒体 2026-06），未交叉验证。
