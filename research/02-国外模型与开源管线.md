## 第一部分 · 海外商业 AI 视频模型（闭源 / API / SaaS）

### 1. OpenAI Sora 2（含 Sora 2 Pro、Sora App 社交化短剧）— ⚠️ 已关停

- **来源链接**：官方公告 https://openai.com/index/sora-2/ ；关停说明 https://help.openai.com/en/articles/20001152 ；横评 https://m.thepaper.cn/newsDetail_forward_31715791
- **类别**：闭源文/图生视频 + 原生音画同步；消费端 iOS 社交 App
- **核心能力**：
  - 2025-09-30 发布 Sora 2，原生同步生成对白 + 音效 + 环境声；物理真实感、可控制性较 Sora 1 大幅提升。
  - Sora App（2025-10-01 上线美区）类 TikTok 短视频社交流，支持"基于他人上传素材二次生成"的协作短剧玩法；上线 5 天破百万下载，登顶美区 App Store。
  - 2025-10-16 更新：标准版 15s、Pro 25s；Pro 网页端"故事板（Storyboard）"功能，可跨镜头保持角色一致。
  - arXiv:2601.17737 横评中 Sora2-Pro 在"视觉吸引力 4.8 / 物理规律符合 4.5"两项居首。
- **在真人写实短剧场景的优秀点**（适合情感向）：
  1. 微表情/口型：澎湃实测中文提示词可生成中文脱口秀演员，挑眉、嘴角上扬等微表情捕捉到位，口型严丝合缝（Veo 3 同期只能出说英语的外国人）。
  2. 情感感染力：ai-in-real-life 实测指出 Sora 2 生成的情绪短片"极擅长操纵观众情绪"，哭戏、温情氛围的光影与表演节奏在同代模型中领先。
  3. 角色跨镜一致：通过 ingredient reference image（成分参考图）可让同一角色跨镜头长相一致；Disney 合作期内曾演示 20–25 秒电影级片段。
- **局限或门槛**：
  - **已不可用**：2026-04-26 消费端/App 关闭，2026-09-24 API 关闭，OpenAI 明确无一对一替代 API；原因为算力成本（传约 1500 万美元/天）、收入不及预期、转向企业级/世界模型研究。
  - 中文提示词夹英文时英文对白发音不准；复杂体操/高难物理动作仍翻车。
  - 原定价：ChatGPT Plus $20/月（720p、5–10s）、Pro $200/月（1080p、20–25s）；免费用户后期被限到每天 6 条。
- **适用环节**：视频生成（已退役，仅作历史标杆参考）。
- **时效与证据类型**：官方发布 2025-09-30；澎湃实测 2025-10-02；OpenAI 官方关停公告 2026-03-24；Engadget/中新网 2026-03-25 报道。

### 2. Google Veo 3 / Veo 3.1（含 Veo 3.2 传闻）

- **来源链接**：官方 https://goo.gle/veo-3 ；横评 https://pick-right.com/tools/veo-3/ ；https://aiunpacking.com/review/google-veo/
- **类别**：闭源文生视频 + 原生 48kHz 三轨音轨（对白/音效/环境声）；在 Gemini / Flow / Vertex AI 内可用
- **核心能力**：
  - Veo 3（2025-05）首发原生音画同步；Veo 3.1（2025-10 发布，2026-01 加入真 4K 原生细节重建，非超分）。
  - **参考图控制**：支持首帧/尾帧/参考图，可锁定角色与场景。
  - **原生音频**：对白 + 环境声 + 音效三轨分离生成，无需后期配音对齐。
  - 通过 Gemini API 调用，与 Vertex AI 深度集成。
- **优秀点**：
  1. 音画同步的音质与对白准确度目前业内领先。
  2. 物理合理性较好（物体交互、碰撞、光影）。
  3. 4K 原生细节重建（非插值超分），近景可用度高。
- **局限**：
  - 中文对白支持弱于 Sora 2（Veo 3 同期只能稳定生成英文对白）。
  - 生成时长较短（8 秒左右），长片段需多段拼接。
  - API 定价较高，Vertex AI 计费。
- **适用环节**：视频生成（尤其需要原生音频时）。

## 第二部分 · GitHub 开源本地管线（ComfyUI 为主）

### 角色一致性方案

| 方案 | 作用 | 说明 |
|---|---|---|
| **IP-Adapter** | 用参考图控制风格/内容 | 最早普及的参考图方案，与 ControlNet 兼容 |
| **PuLID** | ID 保真的人脸一致性 | 无需训练 LoRA，秒级提取 ID，跨姿态/妆容/光���保持 |
| **InstantID** | 单图零样本人脸锚定 | 只需一张图即可，无需微调；与 ControlNet 组合使用 |
| **ConsisID** | 视频人脸一致性 | 针对视频生成场景，解决长视频人脸漂移 |
| **LoRA** | 个别角色的深度定制 | 需要训练，效果最好但成本最高 |

**实践建议**：PuLID / InstantID 做通用锚定，
遇到需要固定特定角色的段落再训 LoRA。

### 口型与表情驱动

| 方案 | 作用 |
|---|---|
| **LatentSync** | 高精度唇形同步，业界主流 |
| **MuseTalk** | 实时口型（30fps+），延迟低 |
| **LivePortrait** | 表情/头部姿态驱动，人脸动画质量高 |
| **EchoMimic / Hallo** | 音频驱动的整脸+身体表演 |
| **Wav2Lip / SadTalker / Diff2Lip** | 经典方案，速度与质量折中 |

### 本地训练与微调

- **ai-toolkit**（ostris）：一站式训练框架，图像/视频 LoRA/DreamBooth 都支持
- **SimpleTuner**：轻量微调方案
- 显存要求：通常 12–24 GB 起步，24 GB 舒适

### 一键短剧 pipeline

社区已有若干端到端工作流，把「剧本 → 分镜 → 角色一致性 → 视频生成 → 口型 → 配音 → 剪辑」串成一条命令。

**实际使用建议**：不要追求全自动。分镜与角色一致性
这两个环节仍需人工确认——全自动流程最容易在这两步
产出不符合预期的结果，返工成本比手工检查更高。
